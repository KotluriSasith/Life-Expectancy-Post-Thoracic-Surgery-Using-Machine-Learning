# 🫁  Life-Expectancy-Post-Thoracic-Surgery-Using-Machine-Learning
Predicts 1-year survival after thoracic surgery using ML. Uses PCA and models like Random Forest, Decision Tree, XGBoost, and Stacking. Built with Python, Flask, and Scikit-learn. Offers a web UI for data upload, training, and prediction. Dockerized for easy deployment.
## 🚀 Features

- Upload and preview medical datasets
- Preprocess data with Label Encoding and PCA
- Train and evaluate models:
  - Random Forest
  - Decision Tree
  - XGBoost
  - Hybrid Stacking Ensemble
- Predict patient survival probability based on 16 medical inputs
- Web interface built with Flask
- Containerized with Docker for easy deployment
